uses its bundled Python through the orchestrator; no experiment package installs
are needed. Scripts are reference preparation/packaging only, not case-specific
CAD reconstruction generators. Source-derived images are regenerated by:

```powershell
.venv/Scripts/python.exe try4/scripts/prepare_phase12.py --inventory
.venv/Scripts/python.exe try4/scripts/annotate_sources.py
.venv/Scripts/python.exe try4/scripts/prepare_phase12.py
```

Inspect existing files first: these preparation commands overwrite Phase 1
reference outputs deterministically. Do not use them to replace frozen future
generation/transfer records. No transfer-method freeze is claimed at this stage.
